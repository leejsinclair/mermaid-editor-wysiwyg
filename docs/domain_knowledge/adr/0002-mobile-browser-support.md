# ADR 0002: Mobile browser support

**Status**: Accepted (2026-10-22, feature 007-blueprint-redesign)

Feature 002 FR-021 supported desktop Chromium and Firefox only and excluded Safari and mobile browsers. With the
Blueprint Studio redesign the editor adds mobile browser support (Chrome on Android and Safari on iOS; desktop Safari stays unsupported),
usable by touch down to 360 px wide. Supporting only
narrow desktop windows (down to 768 px or 360 px) was considered and rejected so that authors can work on a phone,
accepting touch-gesture design and mobile test runs as part of the redesign.
