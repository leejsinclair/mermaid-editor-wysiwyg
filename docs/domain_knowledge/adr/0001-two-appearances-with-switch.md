# ADR 0001: Two appearances with a switch

**Status**: Accepted (2026-10-22, feature 007-blueprint-redesign)

Feature 002 fixed the editor to one light theme (002 FR-022). For the Blueprint Studio redesign the editor gets two
appearances, Blueprint Studio by default and Light, with a switch in the header. A single Blueprint appearance was
considered because it needs only one palette verified for contrast. It was rejected so that users keep a light,
print-friendly option, accepting that every surface and accessibility check must hold in both appearances.
