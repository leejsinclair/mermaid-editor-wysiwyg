# Behaviour Checklist: 006-import-review-fixes

**Specification**: [spec.md](../spec.md) | **Verification Plan**: [plan.md](../plan.md#verification-plan) | **Tasks**: [tasks.md](../tasks.md)

## US1-AS1

> **Given** C4 source generated by the editor for an element labelled `R&D` with description `"fast" <cheap>` and technology `C#`, **When** it is imported, **Then** the element's label, description and technology read `R&D`, `"fast" <cheap>` and `C#`.

- **BI-001** Expresses: FR-001, US1-AS1. Verified by: VO-001.
  - **Given** C4 source the editor generated for an element labelled `R&D`, described `"fast" <cheap>`, with technology `C#`
  - **When** it is imported
  - **Then** the element's label reads `R&D`, its description `"fast" <cheap>` and its technology `C#`

## US1-AS2

> **Given** that imported diagram, **When** its source is generated, **Then** it equals the source that was imported.

- **BI-002** Expresses: FR-002, US1-AS2, EC-03. Verified by: VO-003.
  - **Given** a C4 diagram of any supported kind holding every character the editor escapes, including a field typed as `#38;`
  - **When** its source is generated, imported and generated again, three times over
  - **Then** every generated source equals the source that was imported
  - **And** the field typed as `#38;` still reads `#38;`

## US1-AS3

> **Given** C4 source with escapes in a boundary label, a relationship label, a relationship technology and the diagram title, **When** it is imported, **Then** each is decoded the same way flowchart and sequence labels are.

- **BI-003** Expresses: FR-001, US1-AS3. Verified by: VO-002.
  - **Given** C4 source with escapes in a boundary label, a relationship label, a relationship technology and the diagram title
  - **When** it is imported
  - **Then** each of them reads the same text a flowchart label with the same escapes decodes to

## US2-AS1

> **Given** a valid diagram in the paste area with its preview shown, **When** the developer empties the paste area, **Then** at once (before any preview delay) Import is unavailable and the previous preview is no longer shown as importable.

- **BI-004** Expresses: FR-003, US2-AS1, EC-02. Verified by: VO-005.
  - **Given** a valid diagram in the paste area with its preview shown
  - **When** the developer empties the paste area, or leaves only white space in it
  - **Then** at once, before the preview delay, Import is unavailable
  - **And** the previous preview is no longer shown

## US2-AS2

> **Given** the paste area was just emptied, **When** the developer activates Import by pointer or keyboard within the preview delay, **Then** no diagram is created.

- **BI-005** Expresses: FR-004, US2-AS2. Verified by: VO-006.
  - **Given** the paste area was just emptied
  - **When** the developer activates Import by pointer or by keyboard within the preview delay
  - **Then** no diagram is created

## US2-AS3

> **Given** valid text A with its preview shown, **When** the developer changes it to valid text B, **Then** Import is unavailable until B's preview is ready, and activating it then creates diagram B, never A.

- **BI-006** Expresses: FR-003, FR-004, US2-AS3, EC-01. Verified by: VO-007.
  - **Given** valid text A with its preview shown
  - **When** the developer changes it to valid text B
  - **Then** Import is unavailable until B's preview is ready
  - **And** activating Import then creates diagram B, with none of A's content

## US2-AS4

## US2-AS5

## US3-AS1

> **Given** a flowchart whose `%%{init: … }%%` directive spans several lines, **When** it is pasted, **Then** the diagram is detected as a flowchart, imports, and the report lists the directive once as ignored with its starting line number.

- **BI-009** Expresses: FR-006, US3-AS1, EC-04. Verified by: VO-011.
  - **Given** a flowchart whose init directive spans three lines, and one whose directive is on one line
  - **When** each is pasted
  - **Then** each is detected as a flowchart and imports
  - **And** the report lists its directive once, as ignored, on line 1

## US3-AS2

> **Given** a sequence or C4 document with a multi-line init directive, **When** it is pasted, **Then** its type is detected correctly.

- **BI-010** Expresses: FR-006, US3-AS2. Verified by: VO-012.
  - **Given** a sequence document, and a document of each C4 kind, each with a multi-line init directive
  - **When** it is pasted
  - **Then** its type, and for C4 its kind, is detected correctly

## US3-AS3

> **Given** a document with a complete first flowchart followed by a second `flowchart` header and more nodes, **When** it is imported, **Then** only the first diagram's content is parsed and imported, the import does not fail because of the second diagram, and the report lists the second diagram as not imported with its line number.

- **BI-011** Expresses: FR-007, US3-AS3, EC-08. Verified by: VO-014.
  - **Given** a complete first flowchart followed by a second `flowchart` header and more nodes
  - **When** it is imported
  - **Then** only the first diagram's nodes are in the result
  - **And** the import does not fail because of the second diagram
  - **And** the report lists the second diagram as not imported, with its header's line number
  - **And** a directive line that starts with a diagram word is not taken for a header

## US3-AS4

> **Given** a directive that opens with `%%{` but is never closed, **When** it is pasted, **Then** the dialog reports the problem with its line number rather than guessing a diagram type from text inside the directive.

- **BI-012** Expresses: FR-006, US3-AS4. Verified by: VO-013.
  - **Given** a directive that opens with `%%{` but is never closed
  - **When** it is pasted
  - **Then** the problem is reported with the directive's first line number
  - **And** no diagram type is taken from text inside the directive, and Import stays unavailable

## US4-AS1

> **Given** a flowchart with an asymmetric-shape node on line 7, **When** it is previewed, **Then** the report entry for line 7 names the asymmetric shape and its reason, and ends with "Kept as a rectangle."

- **BI-013** Expresses: FR-008, US4-AS1. Verified by: VO-016.

## US4-AS2

- **BI-014** Expresses: FR-008, US4-AS2. Verified by: VO-017, VO-016.

## US4-AS3

> **Given** a chosen or dropped file whose contents cannot be read (removed, permission denied, read error), **When** the dialog tries to load it, **Then** the dialog shows an understandable message that the file could not be read, the paste area and preview are unchanged, and no error escapes unhandled.

- **BI-015** Expresses: FR-009, US4-AS3, EC-06. Verified by: VO-018, VO-019.

  - **When** the dialog tries to load it

  - **And** no error escapes unhandled

## US5-AS1

> **Given** an original and a generated text of 10,000 lines each, **When** the compare view is opened, **Then** it is shown within 2 seconds and the tab stays responsive.

- **BI-016** Expresses: FR-010, US5-AS1. Verified by: VO-020.
  - **Given** an original and a generated text of 10,000 lines each, differing in a few hundred lines
  - **When** they are compared
  - **Then** the comparison is complete within 2 seconds
  - **And** every differing line is marked

## US5-AS2

> **Given** texts so large or so different that the exact comparison would pass its work limit, **When** the compare view is opened, **Then** it shows both texts side by side, marks unchanged lines at the start and end as same and the middle as changed, and states plainly that the marking was simplified for size.

- **BI-017** Expresses: FR-010, US5-AS2. Verified by: VO-021, VO-022, VO-025.
  - **Given** texts so different that the exact comparison would pass its work limit
  - **When** the compare view is opened
  - **Then** it shows both texts side by side
  - **And** the unchanged lines at the start and end are marked same and the middle is marked changed
  - **And** the view states plainly that the marking was simplified for size
  - **And** memory stays bounded, not growing with the product of the two line counts

## US5-AS3

> **Given** texts within the work limit, of any length up to the file limit, **When** compared, **Then** the result marks a minimal set of removed and added lines, as the current comparison does, and no simplification note is shown.

- **BI-018** Expresses: FR-010, US5-AS3. Verified by: VO-023.
  - **Given** texts within the work limit, including the cases the current comparison is tested with
  - **When** compared
  - **Then** the result marks a minimal set of removed and added lines
  - **And** it is not marked as simplified
